# 危険操作前ゲート

shell や sandbox 上は実行できても、影響範囲が大きい操作の前に使う確認ゲート。

## 発火条件

次の操作前に停止する。

- 依存関係の追加。
- CI/CD または GitHub Actions の変更。
- 認証、秘密情報、権限、データ保存先の変更。
- 破壊的 git 操作。
- 大量のファイル削除、移動、リネーム。
- `docs/plan.md` または `docs/Todo.md` のロードマップ範囲やフェーズゲートを変える編集。
- 明示的な Issue / PR フロー外で、外部サービスや GitHub の状態を変更するスクリプト実行。

## 提示する情報

Manager または Member Codex は次を人間に提示する。

- 実行したい操作
- 分かっている場合は、実行コマンドまたは編集内容
- 操作が必要な理由
- 影響するファイル、ブランチ、外部システム
- 検討したより安全な代替案
- 戻し方または復旧方法

## 人間レビュー観点

人間に次を確認してもらう。

- 現在の Issue に必要な操作である。
- 影響範囲が理解できている。
- 戻し方が現実的である。
- ロードマップ、CI、認証、データ挙動などを暗黙に変えていない。

## 再開条件

人間が明示的に承認した後にだけ進める。承認されない場合は、より安全な代替案を選ぶか、ブロッカーとして報告する。
